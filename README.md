# Loading Screen Gold — A Tip in 200 Characters

Entry for the make.fun competition "Loading Screen Gold: A Tip in 200 Characters". The entry is a single loading-screen tip, 86 characters long, written for a stressed developer and their AI coding agent at the same time: "Tip: Your agent is not stuck. It is politely waiting for you to stop watching it work." The joke lands on a twist — the agent is not frozen, the human hovering over it is the bottleneck — and it works at a glance, with no tired coffee, deadline, or compile jokes.

Run `python3 main.py` and the tip is written exactly, with no trailing newline, to the absolute path `/output/entry.txt`. The program uses only the Python standard library (`pathlib`) and creates the output directory if it does not exist yet.
